依主題整理的 YouTube 頻道與實用網站

你提供資料時，每筆需要這些欄位

沿用 spec/article/data.md 的寫法，改成新檔（例如 spec/sites/data.md）。四種版面用的是同一組欄位，選哪個都不用改資料。

typeyoutube 或 site
name頻道或網站名稱
url連結
intro介紹，一到兩句
handleYouTube 的 @帳號選填，沒填就從網址抓
tags主題，空白分隔選填，D 版面用來分組
lang中文 / 英文 / 日文選填
# type
* youtube
# name
* ByteByteGo
# url
* https://www.youtube.com/@ByteByteGo
# intro
* 系統設計圖解頻道，用動畫拆解快取、
  訊息佇列、資料庫擴展等後端架構題目。
# tags
* 系統設計 後端
# lang
* 英文
