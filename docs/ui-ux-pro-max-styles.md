## 如何使用

透過 `ui-ux-pro-max` Skill 的搜尋功能，可以查詢特定風格的詳細資訊：

```bash
# 生成完整設計系統（推薦）
python3 .agent/skills/ui-ux-pro-max/scripts/search.py "SaaS dashboard fintech" --design-system -p "MyProject"

# 搜尋特定風格
python3 .agent/skills/ui-ux-pro-max/scripts/search.py "glassmorphism" --domain style

# 持久化設計系統（跨 session 使用）
python3 .agent/skills/ui-ux-pro-max/scripts/search.py "SaaS dashboard" --design-system --persist -p "MyProject"

# 搜尋特定技術堆疊的最佳實務
python3 .agent/skills/ui-ux-pro-max/scripts/search.py "responsive layout" --stack html-tailwind
```
