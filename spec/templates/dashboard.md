## 3. 頁面：訂單

### 3.1 功能

| 功能 | 規格 |
|---|---|
| 狀態頁籤 | 全部（12）／待付款（1）／已付款（2）／出貨中（3）／已完成（5）／已取消（1），數字隨狀態變更即時更新 |
| 搜尋 | 比對訂單編號或顧客姓名，輸入即篩選（debounce 200ms）；頂部列的全域搜尋按 Enter 會帶關鍵字切到本頁 |
| 排序 | 點「日期」「金額」欄標題切換升冪／降冪，預設日期降冪 |

| 勾選 | 每列核取方塊＋表頭全選（含半選狀態）。切換狀態頁籤、搜尋、換頁時清除勾選，批次操作只作用在畫面上看得到的訂單 |
| 批次操作 | 勾選後出現操作列：「標記為出貨中」。只會改變「已付款」的訂單，其他狀態略過，toast 顯示「已更新 N 筆，略過 M 筆」 |
| 詳情抽屜 | 點列從右側滑出（手機為全螢幕底部抽屜），見 3.3 |
| 匯出 | 「匯出 CSV」按鈕**停用**，tooltip「示範版未開放」 |

### 3.3 訂單詳情抽屜

- 標題：訂單編號＋狀態徽章
- 顧客：姓名、Email（shared-data 人物表）
- 收件地址：一律「台北市大安區示範路 100 號」（示範用，不逐筆設定）
- 商品明細：品名、規格、單價、數量、小計
- 金額：商品小計、運費、合計
- 付款方式
- 狀態時間軸：依目前狀態顯示已走過的節點（下單 → 付款 → 出貨 → 完成；已取消則為 下單 → 取消）
- 操作：「更改狀態」下拉（選後立即生效並 toast「狀態已更新」，列表同步）、「列印出貨單」**停用**、關閉（✕、Esc、點遮罩）

### 3.4 狀態

- 搜尋無結果：空狀態插圖＋「找不到符合「關鍵字」的訂單」＋「清除搜尋」按鈕
- 進入本頁：表格骨架屏 0.6 秒後顯示資料（每次切到本頁都會出現，展示載入樣式）
- 手機：表格改為卡片列表，每張卡顯示編號、顧客、金額、狀態；勾選與批次操作保留

### 新增商品對話框

| 欄位 | 元件 | 驗證 |
|---|---|---|
| 商品名稱 | 文字輸入 | 必填，最多 20 字 |
| 分類 | 下拉 | 必填 |
| 售價 | 數字輸入（前綴 NT$） | 必填，1–99,999 整數 |
| 庫存 | 數字輸入 | 必填，0–9,999 整數 |
| 標籤 | 核取方塊：新品／熱銷／限量 | 選填 |
| 立即上架 | 開關 | 預設開 |

- 送出時逐欄顯示錯誤訊息（欄位紅框＋下方文字）；全部通過 → 按鈕載入 0.8 秒 → 關閉對話框、新商品出現在列表第一列、toast「已新增商品」。
- 新增的商品只存在記憶體，「重設」即消失。

### 使用者選單

### Toast

右上（手機為底部）出現，3 秒自動消失，可手動關閉。成功／資訊／錯誤三種樣式。
