## 4. 候選新增項目

### 版型

| 候選 | 理由 |
|---|---|
| 部落格／內容雜誌 | 各大範本集都有；適合展示排版，和「和紙編輯」最搭 |
| 作品集／個人品牌 | 設計師、攝影師、自由工作者需求大 |
| 餐廳／咖啡店 | 在地接案最常見：菜單、營業時間、地圖 |
| 預約／排程 | 診所、美容、健身；選時段＋表單流程適合展示（原 `booking.md` 規格可重新評估） |
| 在地專業服務（律師、裝修、房仲） | 最拿不定風格的客群 |
| 文件站／說明中心 | SaaS 客戶常需要：側欄目錄、搜尋、程式碼區塊 |
| AI 聊天／客服介面 | 2026 年已是獨立類別 |
| 登入註冊、結帳流程 | 小型但幾乎每案都有，可當加分項 |

### 風格

| 候選 | 理由 |
|---|---|
| Bento Grid | 獨立主流風格，與現有八種不重疊 |
| 瑞士國際主義 | 強網格大字級，偏設計感，和「企業專業」區隔 |
| 黏土擬態／Kawaii | 補「可愛、親切」路線：B2C、兒童、寵物 |
| Aurora／漸層網格 | AI 新創常見，可和「暗色科技」做亮暗對比 |
| Y2K／Frutiger Aero | 年輕品牌、活動頁 |
| 復古像素（8-bit／Win98） | 遊戲、創意工作室，展示效果強 |
| 自然有機 | 大地色、圓弧，對應餐廳、民宿、健康 |
| 手繪拼貼 | 文創、教育、手作，和「新粗野」區隔 |
