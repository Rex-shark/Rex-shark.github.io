# 設計範本（Design Templates）規格書

> 狀態：規格撰寫中（2026-11-09 起）。本目錄是「設計範本」的**權威資料來源**：假資料、靜態功能、驗收標準都以這裡為準，實作不得自行增減。
> 程式尚未開始；現有網站（首頁、`/gallery`、`/styles/*`、`/projects/*`）**一律不動**。

---

## 1. 目的

接案時，客戶常說不出自己要什麼風格。設計範本讓 Rex 打開一頁，**同一份內容、同一套功能**，當場切換不同設計風格給客戶看，讓客戶快速挑出方向。

- 客戶比較的是「風格」，所以除了風格以外的一切都必須相同：資料、文案、版面區塊、可操作的功能、狀態。
- 客戶選定後，該風格的 `DESIGN.md`（Google design.md 格式，見 `read-design-spec` skill）可直接帶進客戶專案，當作設計規範的起點。

長期目標：取代現有的「設計實驗室」（`/gallery`，23 種風格首頁）。取代時機另議，**本階段兩者並存**。

## 3. 核心原則（實作與審查都以此檢查）

1. **資料單一來源**：每個版型的假資料只有一份，所有風格讀同一份。文案、數字、圖片、排序全部一致。
2. **功能單一實作**：互動邏輯（篩選、排序、購物車、表單驗證、步驟流程）只寫一次，與風格無關。風格層**不得**新增、刪除或改變任何功能。
3. **結構一致**：同一版型在所有風格下有相同的區塊與元素順序。風格可改變的只有：顏色、字體、間距、圓角、陰影、邊框、透明度、背景裝飾、動畫質感。
   - 例外：純裝飾元素（如玻璃態的背景漸層色塊）可由風格自行加入，但不得帶有資訊或可操作性。
4. **切換風格保留狀態**：使用者在 A 風格加了購物車、開了篩選、走到預約第 3 步，切到 B 風格時狀態完全保留。這是展示給客戶看的重點。
5. **純前端靜態**：沒有後端、沒有真實付款、不送出任何資料。所有「送出」都只在前端模擬（延遲約 0.8 秒的載入狀態 → 成功畫面）。重新整理頁面即回到初始資料。
6. **各種狀態都要有**：每個版型的規格都列出必須呈現的空狀態、載入中、錯誤、停用狀態，讓客戶看得到風格在這些狀態下的樣子。
7. **語言**：介面與假資料一律繁體中文（台灣用語）；金額 `NT$1,280` 格式；日期 `2026/11/09`。
8. **響應式**：每個版型都要支援桌機（≥1280）、平板（768）、手機（375）。各版型規格寫明手機版的版面變化。
9. **無障礙底線**：文字對比 ≥ 4.5:1（大字 ≥ 3:1）、所有互動元素可用鍵盤操作且有可見 focus、尊重 `prefers-reduced-motion`。玻璃態與柔和 UI 特別容易對比不足，須逐一檢查。

## 4. 展示器（Viewer）

客戶實際看到的外框，與版型內容分開。

### 4.1 入口

- 首頁導覽列「設計實驗室」旁新增按鈕 **「設計範本」** → 連到 `/templates`。現有「設計實驗室」按鈕保留不動。

### 4.2 路由

```
/templates                         → 範本總覽（選版型、選風格）
/templates/<template>              → 版型展示，預設第一個風格（minimal）
/templates/<template>?style=<slug> → 指定風格（網址可直接分享給客戶）
```

版型內的子頁（例如購物網站的商品詳情、儀表板的訂單頁）用版型內部狀態切換，**不另開路由**，避免切換風格時跳頁。

### 4.3 範本總覽頁 `/templates`

- 標題「設計範本」與一句說明：同一份內容，切換不同風格比較。
- 版型卡片（每版型一張）：名稱、適用情境、可用風格 chip（點 chip 直接進入該風格）。
- 本頁本身採中性設計（不套任何範本風格），避免干擾客戶判斷。

### 4.4 展示工具列（每個版型頁都有）

固定在畫面底部中央的浮動工具列，**不受範本風格影響**，固定中性樣式。**單列、寬度固定**：版型與風格再多，工具列都不會變寬，選項放在從工具列上方展開的面板裡（2026-11-24 改版，為了之後加入更多版型與風格）。

| 功能 | 說明 |
|---|---|
| 版型切換 | 按鈕顯示目前版型；點開「版型」面板，依分組（後台系統、前台網站…，見 `registry.ts` 的 `TEMPLATE_GROUPS`）列出名稱＋適用情境，點選後切換並關閉面板，保留目前風格 |
| 風格切換 | 「‹ 目前風格 ›」：左右箭頭（或鍵盤 `←` `→`）依序輪換；點中間開「風格」面板，格狀列出所有風格（色票＋中英文名），可依亮色／暗色篩選；點選後面板不關閉，方便連續比較 |
| 裝置寬度 | 桌機／平板／手機三段，把範本內容框限在對應寬度內預覽（手機寬度下不顯示） |
| 風格說明 | 開側欄顯示該風格的定位、適合產業、主要色票與字體（內容取自該風格 `DESIGN.md`），可複製 `DESIGN.md` 全文 |
| 重設 | 把版型狀態恢復初始資料（購物車清空、篩選還原等） |
| 隱藏工具列 | 收成一顆小按鈕，讓客戶看完整畫面 |
| 返回 | 回 `/templates` |

- 面板：點工具列外面或按 `Esc` 關閉（焦點回到觸發按鈕）；面板內可用方向鍵移動
- 手機：同樣單列；「返回、風格說明、重設、隱藏」收進「⋯」選單

## 5. 實作方向（概略；完整做法見 [implementation.md](implementation.md)）

```
src/templates/
├── data/            # 共用假資料（品牌、商品、門市…），對應 shared-data.md
├── <template>/
│   ├── data.ts      # 該版型專屬假資料，對應 <template>.md
│   ├── state.ts     # 狀態與動作（reducer / store），與風格無關
│   └── View.tsx     # 唯一一份版面結構，只透過風格 token / 樣式槽位取樣式
├── styles/<slug>.ts # 風格：CSS 變數 + 各元件樣式槽位（按鈕、卡片、輸入框、表格…）
└── viewer/          # 總覽頁、展示工具列
```

- 狀態放在展示器層級（風格的外層），切風格只換樣式不重建狀態。
- 所有範本路由 lazy load，不增加正式首頁的 bundle 大小。
- 範本內的圖片（商品照、門市照、情境照）統一一套，所有風格共用。由 Codex image_gen 生成，清單見 [images.md](images.md)。
