> 情境：青森選物的官方網路商店。商品資料引用 [shared-data.md](shared-data.md) 第 3 節（12 件），本檔不另寫商品數值。

## 4. 購物車抽屜

右側滑出（手機為全螢幕）。**初始為空**。

| 元素 | 規格 |
|---|---|
| 標題 | 購物車（N 件） |
| 免運進度 | 「再買 NT$X 即可免運」＋進度條；達標後顯示「已享免運 🎉」改為成功樣式（emoji 只在此處使用，若風格不適合可換 icon） |
| 商品列 | 縮圖、名稱、規格、單價、數量步進器（1 ～ min(庫存,10) 扣掉同商品其他規格的件數）、移除按鈕；同商品同規格合併為一列 |
| 移除 | 移除後 toast「已移除 商品名」附「復原」按鈕（5 秒內可還原） |
| 折扣碼 | 輸入框＋「套用」。`QINGSEN10` → 商品小計 9 折，顯示「已套用 QINGSEN10（−NT$X）」與移除按鈕；其他代碼 → 錯誤「折扣碼無效或已過期」 |
| 金額 | 商品小計、折扣、運費（依折扣後金額判斷免運；抽屜內一律以宅配計算）、合計 |
| 按鈕 | 「前往結帳」（購物車空時停用）、「繼續購物」（關閉抽屜） |
| 空狀態 | 插圖＋「購物車是空的」＋「去逛逛」按鈕（關閉抽屜並回列表） |

金額計算：

```
小計 = Σ(單價含規格加價 × 數量)
折扣 = 套用 QINGSEN10 時 round(小計 × 0.1)，否則 0
運費 = (小計 − 折扣) ≥ 1,500 ? 0 : (宅配 100 ／ 超商取貨 60)
合計 = 小計 − 折扣 + 運費
```

## 5. 頁面：結帳

單頁結帳，左側表單、右側訂單摘要（手機摘要收合在頂部，可展開）。

### 5.1 表單

| 區塊 | 欄位 | 元件 | 驗證 |
|---|---|---|---|
| 聯絡資訊 | 姓名 | 文字 | 必填 |
| | 手機 | 文字 | 必填，`09` 開頭 10 碼 |
| | Email | Email | 必填，格式正確 |
| 配送方式 | 宅配／超商取貨 | 單選卡片 | 預設宅配；切換時摘要運費即時更新 |
| 收件地址（宅配） | 縣市 | 下拉（22 縣市） | 必填 |
| | 地址 | 文字 | 必填 |
| 取貨門市（超商） | 門市 | 下拉：示範門市 A／B／C | 必填 |
| 付款方式 | 信用卡／LINE Pay／ATM 轉帳／貨到付款 | 單選卡片 | 預設信用卡；**不顯示任何卡號欄位**，下方固定提示「示範網站，不會實際付款」 |
| 備註 | 訂單備註 | 多行文字（選填，最多 100 字，顯示字數） | — |
| 條款 | 我已閱讀並同意購物條款 | 核取方塊 | 必勾 |

- 「送出訂單」：先驗證，錯誤欄位紅框＋訊息，畫面捲到第一個錯誤欄位並 focus；通過 → 按鈕載入 0.8 秒 → 進入完成頁。
- 「← 返回購物車」：回列表並開購物車抽屜。

### 5.2 訂單摘要

商品列（縮圖、名稱×數量、小計）、折扣碼（可在此再輸入）、小計、折扣、運費、合計。
